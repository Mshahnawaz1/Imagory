# App screenshots

Taken from the real app showing a **synthetic** library. Never real photos or real people.
Generated by `frontend/tools/screenshots/`. PNG, window only (no desktop), 1600×1000 unless noted.

| File | Shows |
| --- | --- |
| `main-light.png` | Main window, light theme: sidebar (Library, People, Albums, Sources), filter bar, grid with month headers |
| `main-dark.png` | The same in dark theme |
| `viewer-dark.png` | Photo viewer with the info panel open (date, place, people, file) |
| `sources-light.png` | Sources dialog listing a folder source and a Takeout source |
| `welcome-light.png` | First-run welcome screen |
| `cleanup-light.png` | Clean up Takeout wizard (plan or result step) |

The site imports these through `src/components/Screenshot.astro`, which shows a placeholder
of the same size when a file is missing.
